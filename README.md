# [Store-Front](https://store-front.net)
<p style='font-size:20px;'>A fullstack ecommerce website with the front end written in Angular using TypeScript and the back end using Spring Boot written in Java, all hosted on AWS</p>
<img src='images/store-front-home.png' width='100%'/>
<p style='font-size:20px;'>Implements pagination, search, product view, category view, and checkout using Spring Data JPA, Spring Data Rest, and Spring Web</p>
<img src='images/store-front-cart.png' width='100%'/>
<p style='font-size:20px;'>Dynamic cart functionality built using Angular standalone components with Dependency Injections for state management</p>
<img src='images/store-front-stripe.png' width='100%'/>
<p style='font-size:20px;'>Payment processing powered using Stripe! Test it out using card number 4242 4242 4242 4242</p>
<img src='images/store-front-orders.png' width='100%'/>
<p style='font-size:20px;'>Login and authentication handled using Auth0</p>
